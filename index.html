Bulk Import

Paste rows copied from a spreadsheet, including the header row. Recognized columns (any order, extras ignored, common alternate spellings OK -- e.g. "Youtube Link" or "Year of release"): Artist, Song Title, Director, Category, YouTube Link, Vimeo Link, MVG Link, Year, Release date, Studio, Producer, DP, Editor, Choreographer, Country, Genre 1, Genre 2, Genre 3 (or a single Genre column), Description, Feature, Spotlight, Sponsored, Row #. Include "Row #" to update an existing entry; leave it blank to create a new one.
